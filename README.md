Sales-Performance-Dashboard
A dynamic Power BI dashboard that analyzes sales data across regions, categories, products, and time. Includes KPIs, profit margins, top-selling products, and geographic performance using interactive visuals.
This Power BI project visualizes and analyzes sales performance data across multiple dimensions, including region, product category, and order date.

 🔍 Features
- Interactive dashboard with drill-down capability
- Top 10 product performance by sales
- Profit margin calculations
- Regional sales map visualization
- Category-wise pie and bar charts
- KPI cards for total sales, profit, and margin

📊 Built With
- Microsoft Power BI
- Sample sales dataset (Excel-based)

📁 Files Included
- `SalesPerformanceDashboard.pbix`: Main Power BI report file
- `SalesData.xlsx`: Source dataset

---

💡 Purpose
This project was built for data visualization practice and to demonstrate core Power BI capabilities like DAX, filters, custom visuals, and layout design.
